{{- /* of a file of assets/images/ (fingerprinted URL, real width and height so that the page does not jump while loading, native lazy loading). Usage: {{ partial "img.html" (dict "src" "/images/x.jpg" "alt" "..." "eager" false) }} Options: "resize" (Hugo image processing spec, e.g. "240x webp"), "priority" (fetchpriority="high", for an eager image that is the largest of the page), "width" and "height" (required for SVG files, whose size Hugo cannot read), "zoom" (when assets/images/_hd. exists, a click opens that high-definition version in the viewer of main.js; images without one are not clickable and not part of the viewer's navigation), "caption" (shown by the viewer). The image shown comes from photo.html: a photo may exist only as its "_hd" file, of which the page shows a 1200 px copy. */ -}} {{- $path := strings.TrimPrefix "/" .src -}} {{- $res := false -}} {{- if or .width .resize -}} {{- /* SVG files (sizes given) and explicitly resized images: the file. */ -}} {{- $res = resources.Get $path -}} {{- if not $res }}{{ errorf "image %q not found in assets/" $path }}{{ end -}} {{- else -}} {{- $res = partial "photo.html" .src -}} {{- end -}} {{- with .resize }}{{ $res = $res.Resize . }}{{ end -}} {{- $width := .width -}} {{- $height := .height -}} {{- if not $width }}{{ $width = $res.Width }}{{ $height = $res.Height }}{{ end -}} {{- $zoom := cond (.zoom | default false) (partial "hd-url.html" .src) "" -}} {{- with $zoom }}{{ end -}} {{- if $zoom }}{{ end -}} {{- /* */ -}}
